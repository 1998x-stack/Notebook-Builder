# ResNet / Deep Residual Learning — notebook-builder executable tutorial

## Contents

- `ResNet_Deep_Residual_Learning_Complete_Tutorial.ipynb` — **self-contained** Chinese annotated tutorial, saved outputs, diagrams, model code, training, validation.
- `ResNet_Deep_Residual_Learning_Complete_Tutorial.html` — read-only rendered lesson.
- `resnet_paper_1512_03385_spec.json` — Notebook Builder's validated source-of-truth spec, SHA-256 recorded in notebook metadata.
- `figures/` — 13 images generated by actual code execution.
- `artifacts/` — `resnet_toy_state_dict.pt`, `run_manifest.json`, `verification.json`.
- `quality_report.json` — execution-count, stdout, figure and error quality contract.
- `build.log` — notebook execution runner trace.

**Reference:** He, Zhang, Ren, Sun, *Deep Residual Learning for Image Recognition*, arXiv:1512.03385, https://arxiv.org/pdf/1512.03385 (2015; CVPR 2016).

## Run locally

```bash
# Open in JupyterLab and Run All, or use the Notebook Builder included in its source bundle:
python /path/to/notebook-builder/nbuild.py execute \
  ResNet_Deep_Residual_Learning_Complete_Tutorial.ipynb \
  --cwd "$PWD" --timeout 180

python /path/to/notebook-builder/nbuild.py quality \
  ResNet_Deep_Residual_Learning_Complete_Tutorial.ipynb \
  --min-prints 14 --min-figures 9
```

System requires Python 3.11+, torch, numpy, matplotlib, pandas, IPython, nbformat, nbclient, nbconvert, ipykernel. TorchVision is used only when optional real-data / pretrained paths are enabled.

No data downloads. In the normal execution, `RUN_REAL_CIFAR10`, `RUN_REAL_IMAGENET`, `RUN_IMAGENET_TRAIN`, `ALLOW_WEIGHT_DOWNLOAD` are unset / 0. Set them deliberately to opt in to large real-data experiments. A real ImageNet or CIFAR-10 result requires the named dataset, its preprocessing protocol, extensive compute, and complete evaluation. Do not interpret synthetic 3-class results as the original paper's reported metrics.

## Coverage

- ImageNet: ResNet-18, 34, 50, 101, 152 with post-add ReLU and the original bottleneck stride at 1x1 (unlike torchvision-v1.5).
- CIFAR: original 6n+2 family: ResNet-20, 32, 56, 110 with identity/zero-pad Shortcut A and projection Shortcut B.
- Full neural network source included in a code cell; the standalone `.py` in the builder bundle is a convenience, not a requirement.
- Shape, parameter, MAC and gradient checks; synthetic images from independent PRNGs; actual 24-step CPU optimization; inference, accuracy, confusion matrix and saved state_dict reloading; 13 generated figures.
- Explicit opt-in real CIFAR-10 train/eval/checkpoint and ImageNet ImageFolder train/eval/checkpoint utilities. Neither was executed in the offline CPU demo.

## Provenance & limitations

The architecture and numbers are referenced to the original paper (Table 1 and 3/4/6; Sections 3.1, 3.2, 3.4, 4.2). All tutorial figures are newly generated; no plots or images from the PDF are copied. `paper` results are **reported source facts**, not this notebook's measurements. No trained ImageNet model, original large-scale ImageNet training, multi-GPU DDP or COCO/Faster R-CNN detection experiment is represented as completed.

The notebook executes arbitrary Python in the current kernel; it is not a sandbox. Only execute trusted files.
