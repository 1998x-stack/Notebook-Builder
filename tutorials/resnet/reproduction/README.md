# ResNet 2015 real-data reproduction protocols for Colab

These three files are generated by `build_real_cifar.py`, `build_real_imagenet.py`, and `build_real_detection.py`. All are **UNEXECUTED** on their full original datasets. They include full standalone model/dataset/training source (no imported repo .py at runtime) and produce actual numbers **only when executed on licensed official data**.

- `ResNet_2015_CIFAR10_FULL_PAPER_Colab.ipynb` — real CIFAR-10 + 64k SGD steps per model + original 10 architecture variants + ResNet110 5 independent seeds, test evaluation only after complete training; resumable checkpoints to Google Drive. This implements the real-data CIFAR portion of the paper, not the entire paper.
- `ResNet_2015_ImageNet_FULL_Protocol_Colab.ipynb` — original ImageNet ResNet-v1/Plain architecture + authorized ImageNet-1k data + 600k-step / 50k-image evaluation program. Resource and implementation limitations mean it is an **approximation** pending faithful multi-GPU reproduction.
- `ResNet_2015_VOC_COCO_Detection_RealData_Colab.ipynb` — real VOC and COCO annotation loaders + modern torchvision Faster R-CNN, evaluation metrics. This is a **modern research extension, NOT exact 2015 detector reproduction**.

Read `docs/PAPER_REPRODUCTION.md` for absolute requirements, quality gates and reproducibility policy. The older `tutorials/resnet/outputs/ResNet_Deep_Residual_Learning_Complete_Tutorial.ipynb` is only a synthetic-data teaching demonstration, not a publication replication.
